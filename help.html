NDOS - Help (In Development)

Help Subjects:

  • Getting 404 Error on site?
    The content may be deleted for a reason.

  • Getting Server Error on site?
    - Server may be shut down for a reason.

  • Can't setup NDOS?
    Setup file may be broken.
    Make sure you downloaded the setup file on original site.

  • How to backup file system?
    Enter "Tech Mode" and install "EXT" package. Then "ext -backup".

  • Forgot your password?
    Please wait for Release 5 to "Forgot Password" menu on NDOS.
